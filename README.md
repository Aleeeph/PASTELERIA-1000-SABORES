🧁 Pastelería 1000 Sabores



📖 Descripción
Pastelería 1000 Sabores es un proyecto web desarrollado como parte de la evaluación semestral de Desarrollo Fullstack.

El proyecto consiste en una plataforma web para una pastelería, cuyo objetivo es ofrecer una experiencia digital para que los usuarios puedan conocer la empresa, explorar sus productos, consultar información detallada y gestionar sus compras mediante un carrito.

La aplicación busca representar el funcionamiento de una tienda online moderna, incorporando diferentes vistas orientadas tanto a los clientes como a la administración del negocio.

🎯 Objetivos del proyecto
Diseñar y desarrollar una interfaz web atractiva y responsiva.
Implementar una estructura organizada de un proyecto web.
Crear un catálogo de productos para la pastelería.
Permitir a los usuarios registrarse e iniciar sesión.
Implementar un carrito de compras.
Incorporar páginas de detalle de productos.
Crear una sección de administración.
Aplicar conocimientos de desarrollo Frontend y Backend.
Utilizar buenas prácticas de organización y desarrollo de software.
✨ Funcionalidades
👤 Usuarios
Registro de nuevos usuarios.
Inicio de sesión.
Acceso a las funcionalidades de la plataforma.
Navegación entre las diferentes secciones del sitio.
🛍️ Productos

Visualización del catálogo de productos.
Consulta de información individual de cada producto.
Página de detalle de producto.
Navegación organizada por el catálogo.
🛒 Carrito de compras
Agregar productos al carrito.
Visualizar los productos seleccionados.
Gestionar los productos antes de realizar una compra.
📝 Blog
Sección de publicaciones.
Visualización de artículos.
Página individual para el detalle de cada publicación.
📞 Contacto
Página de contacto.
Información relacionada con la pastelería.
Canal de comunicación con los clientes.
🏢 Nosotros
Información sobre la pastelería.
Presentación del proyecto y su identidad.
🔐 Administración
El proyecto incorpora una sección destinada a la administración de la plataforma, separando las funcionalidades administrativas de la experiencia del usuario.
