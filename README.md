🧁 Pastelería 1000 Sabores

Proyecto web desarrollado como parte de la evaluación semestral de Desarrollo Fullstack.

📖 Descripción

Pastelería 1000 Sabores es un proyecto web que busca representar la experiencia digital de una pastelería moderna.

La plataforma permite a los usuarios:

🍰 Conocer la pastelería y su identidad.
🛍️ Explorar el catálogo de productos.
🔎 Consultar información detallada de cada producto.
🛒 Gestionar productos mediante un carrito de compras.
👤 Registrarse e iniciar sesión.
📝 Consultar publicaciones del blog.
📞 Acceder a información de contacto.
🔐 Utilizar funcionalidades destinadas a la administración.

El proyecto busca simular el funcionamiento de una tienda online, incorporando diferentes vistas orientadas tanto a los clientes como a la administración del negocio.

🎯 Objetivos del proyecto
🎨 Diseñar y desarrollar una interfaz web atractiva y responsiva.
📁 Implementar una estructura organizada para un proyecto web.
🍰 Crear un catálogo de productos para la pastelería.
👤 Permitir a los usuarios registrarse e iniciar sesión.
🛒 Implementar un carrito de compras.
🔎 Incorporar páginas de detalle de productos.
🔐 Crear una sección de administración.
💻 Aplicar conocimientos de desarrollo Frontend y Backend.
🧹 Utilizar buenas prácticas de organización y desarrollo de software.
